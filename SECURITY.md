# Security

Report vulnerabilities privately through GitHub Security Advisories on this repository
(Security tab, "Report a vulnerability"). You will get an acknowledgement within a few days and a
coordinated disclosure plan once the report is confirmed. Do not open a public issue for a
security problem.

Lembra is pre-alpha. There is no supported release yet, so there is no version to patch; reports
still matter because they shape the design before code depends on it.
